> **Implementation status:** Provider code path: adyen. Not live-qualified by code alone. Enable provider wallet certificate/domain configuration. See [current coverage](provider-coverage.md).

**Category**: [Digital Wallets](providers/digital-wallets/README.md)  
**Provider**: Apple Inc.  
**Method ID**: `digital-wallet`  
**Integration Mode**: `NATIVE`

Apple Pay enables frictionless 1-tap checkout for iOS and macOS users using biometric Face ID or Touch ID authentication.

---

## Key Benefits

- **Highest Conversion Rate**: Eliminates manual card entry, yielding up to 50% higher checkout completion on mobile devices.
- **Biometric Security & 3DS Shift**: Leverages Secure Element hardware with dynamic cryptograms that qualify for fraud liability shifts.
- **Direct Merchant Processing**: Decryptable tokens can be processed by Stripe, Visa, or certified acquiring partners.
